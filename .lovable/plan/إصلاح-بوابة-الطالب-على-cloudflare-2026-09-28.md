# إصلاح بوابة الطالب على Cloudflare

## النتيجة
- إزالة اعتماد دخول الطالب وولي الأمر على المفتاح السري غير المتاح في Cloudflare.
- إصلاح تعيين كلمة مرور الطالب من حساب المدرس باستخدام جلسة المدرس الحالية.
- إبقاء بيانات الدخول والجلسات والإجابات محمية داخل قاعدة البيانات.

## التنفيذ
1. إضافة عمليات آمنة داخل قاعدة البيانات لتسجيل الدخول، والتحقق من جلسة البوابة، وعرض الاختبارات، وفتحها، وتسليم الإجابات، وتغيير كلمة المرور.
2. السماح فقط لهذه العمليات المحددة بالعمل بالمفتاح العام، مع التحقق من كود الطالب وكلمة المرور أو رمز الجلسة داخل كل عملية.
3. تعديل موقع البوابة ليستخدم المفتاح العام المتاح على Cloudflare بدل المفتاح السري.
4. تعديل حفظ كلمة مرور الطالب ليستخدم حساب المدرس الموثق مباشرة، وإزالة الاستدعاء المتبقي للمفتاح السري.
5. اختبار إضافة طالب بكلمة مرور، وتسجيل دخوله، وفتح اختبار وتسليمه، ثم مراجعة فحص الأمان وحالة الموقع.

## ملاحظة تقنية
- لن يُضاف `SUPABASE_SERVICE_ROLE_KEY` إلى GitHub أو Cloudflare؛ هذا المفتاح غير متاح للمشاريع المُدارة ولا ينبغي كشفه.
- ستظل صلاحيات المدرس والطالب مفصولة، ولن تُفتح الجداول الحساسة للقراءة المباشرة.
